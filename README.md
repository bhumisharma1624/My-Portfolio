# 🌐 Bhumi Sharma — Personal Portfolio (2026)

> A lightweight, responsive personal portfolio website showcasing my work across UI/UX design, front-end development, data analytics, and interactive web projects.

---

## 📌 Overview

This repository contains the source code for my portfolio website. Built with a **Figma-first design mindset** and a clean, minimalist structural code approach, it bridges human-centered digital UI/UX design with responsive web development.

The site highlights my background as a Computer Science Engineering student (GGSIPU), feature projects, technical skill set, virtual internship experiences, and contact details.

---

## ✨ Features

- 🎨 **Minimalist & Modern UI:** Designed with custom typography (`Space Grotesk`, `Inter`, `JetBrains Mono`), structured layout framing, and subtle color accents.
- 📱 **Fully Responsive Layout:** Optimized for seamless navigation across desktops, tablets, and mobile devices with a custom sidebar navigation bar and collapsable mobile menu toggle.
- 🔍 **Interactive Project Search & Filtering:** Dynamic client-side project filtering system to sort work by categories like UI/UX, Front-End, JavaScript, Data, and Python.
- ♿ **Accessible & Semantic:** Built using standard semantic HTML elements, accessible navigation patterns, high-contrast typography, and live screen-reader regions.
- ⚡ **Zero External Dependencies:** Native vanilla JS, raw CSS layouting, and standard web fonts for instant page load times and zero build overhead.

---

## 🛠️ Tech Stack & Assets

- **Structure:** HTML5 (Semantic markup, accessibility attributes)
- **Styling:** CSS3 (Custom variables, CSS Grid, Flexbox, responsive breakpoints)
- **Interactivity:** Vanilla JavaScript (DOM manipulation, dynamic filtering/search, state management)
- **Typography:** Space Grotesk, Inter, JetBrains Mono (via Google Fonts)

---

## 📂 Featured Sections

1. **Hero & Intro:** Quick snapshot, status indicator, primary calls-to-action, and direct social links.
2. **About Me:** Overview of background, educational path, technical intersections, and core interests.
3. **Skills Matrix:** Categorized breakdown of tools across Design (Figma), Web Development (HTML/CSS/JS), Data Analysis (Power BI, SQL, Python), and AI workflows.
4. **Interactive Work Gallery:** Filterable list of case studies, design prototypes, e-commerce clones, interactive JS tools, and web applications.
5. **Experience & Education:** Timeline of virtual internships, academic achievements (B.Tech CSE), and industry certifications.
6. **Contact Section:** Direct email, phone, GitHub, and LinkedIn links.
